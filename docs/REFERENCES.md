## Local project images

Images created by, photographed by, or otherwise licensed for this project should be stored under:

```text
docs/assets/
```

Recommended filenames:

```text
docs/assets/scylla-board-overview.jpg
docs/assets/scylla-installed-cabinet.jpg
docs/assets/scylla-wiring-overview.jpg
docs/assets/scylla-control-panel.jpg
docs/assets/scylla-pinmap-annotated.png
```

## Recommended policy

- Vendor PDFs: link to the official source.
- Vendor pinout images: link to the official source unless redistribution permission is clear.
- Project-owned photos: commit directly under `docs/assets/`.
- Large original photos: resize/compress before committing.
- Very large binary documentation sets: use Git LFS or GitHub Releases rather than normal Git history.
- Annotated diagrams created specifically for this fork can be stored locally if they do not reproduce restricted third-party artwork.
